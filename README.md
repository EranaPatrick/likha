# likha

a place to find and ask about art from independent artists. browse without an account, sign in only to like, follow or send an inquiry.

work in progress, hobby project. fake data for now (see `src/data/artworks.ts`), images in `public/art/` are public domain paintings from wikimedia commons.

## run it

```bash
npm install
npm run dev
```

then open http://localhost:3000

## stack

- next.js (app router) + typescript
- plain css modules
- sqlite + prisma and auth are planned, see TODO.md
